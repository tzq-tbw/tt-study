# Tt-study 独立功能预览

双击 `index.html` 打开。首页保留已确认的 Apple 风格，新增错题本、间隔复习、语境造句、辅助阅读与 API 设置。本目录继续作为隔离预览；2026-10-22 已授权将共享模块生成正式 `../wordbloom.html`，由正式入口兼容旧学习记录。详见 `../../docs/MIGRATION.md`。没有打包或部署。

## 使用

- **错题本**：添加单词 → 检查词条 → 修改释义 → 保存。支持批量、短语、大小写去重。新词次日复习；没有释义的词先补充再自测。
- **每日背诵**：从完整词库固定当天 50 个未学词，每组最多 5 个；忘词先进入下一组，再补新词。支持上一个、本组状态列表和刷新续学。例句默认折叠，展开例句或选择“忘记了”自动进入错题本与今日造句词池；保留手动加入和发音。预览不读取正式学习记录。
- **艾宾浩斯复习**：20 词默认目标、10 词一组。回忆后展开答案，再反馈记得或忘了。忘词组内重练一次、次日再安排；当天最多推进一轮。第 2、4、6 轮分别点亮三个状态灯。
- **语境造句**：今日错词与自由添加分开；自由添加无需先背完。生成例句或最多 10 个目标词的短文，结果保存，可转到辅助阅读。
- **辅助阅读**：导入或选择本地文章，划选后点“针对这段提问”，在输入框自由提问。支持不选正文直接提问、连续追问、取消、失败后重新发送、全文分段总结。提问会打开可拖动悬浮窗。
- **AI 助教**：全站悬浮入口，不占用导航栏目、不铺满窗口。入口按钮和对话窗标题栏都可拖动，位置会保存；方向键可移动标题栏。收起或按 Esc 后保留入口，切换页面不丢草稿或对话。文章引用绑定原文章，可切换自由提问；拖动限制在可见窗口内。
- **每日时报**：日期由新到旧排列，保留今日阅读、上一篇、下一篇和返回今日。内置与导入文章均可删除；删除标记持久保存，可选择同时删除关联对话。
- **设置**：配置 OpenAI 兼容地址、模型及 Key。文本生成共用当前服务，图片 OCR 单独配置视觉模型。可添加多个服务，调整正文字符预算。

## 数据与连接

学习记录只保存在浏览器的 `tt_preview_learning_v1`；Key 单独使用 `tt_preview_keys_v1`，默认保存在 `sessionStorage`，主动勾选记住后才写入 `localStorage`。不访问正式页面的 `wb_*` 数据。学习数据导出不包含 Key。

`library.js` 是从当前正式源码只读提取的 14,484 个词条和 55 篇本地文章的静态副本。基础复习和本地阅读可离线；AI 需要网络及支持浏览器跨域的服务。PDF 解析首次从固定版本的 jsDelivr 地址加载 PDF.js，需要网络；图片识别通过配置的视觉模型完成。导入正文不截断，保存失败会明确提示。

六轮按时完成时为加入后的第 1、2、4、7、15、30 天；下一次间隔从实际完成日计算。日期以浏览器本地日历为准。`core.js` 含旧次数归一化能力，正式入口通过 `migration.js` 启用旧数据兼容，预览不启用。

## 验证

```powershell
node outputs/tt-study-apple-motion/core.test.cjs
node outputs/tt-study-apple-motion/browser.test.cjs
node outputs/tt-study-apple-motion/revision.test.cjs
node outputs/tt-study-apple-motion/ai-client.test.cjs
node outputs/tt-study-apple-motion/floating.test.cjs
```

浏览器测试使用本机 Chrome 与 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径。测试使用独立临时浏览器上下文和模拟 API，不使用个人 Key 或学习记录；截图保存为 `verification-*.png`。

同一 API 地址的请求串行发送并保留至少 1 秒间隔。可识别的暂时性 429 最多重试两次；优先遵循 Retry-After，未提供时分别等待 15、30 秒。限流和额度错误提供中文处理建议，并保留状态码、错误码及 Request ID；连接测试结果留在设置页，直到下次测试更新。预算等不可重试错误直接停止。每次实际网络请求最长等待 120 秒（包含响应体读取），超时不自动重试，问题草稿保留；用户取消与超时分别提示。长文总结保存每个已完成片段，失败或取消后重试可继续，取消排队不会发送请求。此处理不能解除服务端账户额度限制。

已覆盖：日历间隔、逾期/忘词/同日防重复、词条去重、长期文章上下文；浏览器中的添加与刷新、状态灯、自由生成、选段与追问、API 认证失败、移动端溢出及减少动效模式。

新增验证：50 词计划、5 词组承接、例句自动收词、新闻日期和删除持久化、真实鼠标拖选中段/末段、悬浮窗拖动、收起与跨页草稿保留、独立对话隔离、串行队列、限流重试与预算停止、连接测试诊断保留、网络和响应体超时及草稿保留。

真实 API 服务质量、实际跨域可用性、视觉 OCR 准确率和手机真机尚未验收。英语日记与自定义词库在正式入口通过 `extras.js` 接入，独立预览仍不启用。

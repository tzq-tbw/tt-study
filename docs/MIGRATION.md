# 正式入口迁移说明

2026-10-22，用户明确授权将独立预览迁移至正式 `outputs/wordbloom.html`，并上传 GitHub 私有仓库 `tzq-tbw/tt-study`。

## 存储与兼容

首次打开正式入口会校验旧学习数据，再一次性写入 `wb_learning_v2`。已有新版数据时不重复导入。任一数据损坏或写入失败时停止初始化写入并明确提示；不清除旧键，不显示迁移成功。

| 旧记录 | 新版对应 |
| --- | --- |
| 错题本、复习次数 | 逐词状态，大小写去重并保留最高旧轮次；不生成旧完成日志 |
| 每日错词、AI 文章 | 按日期保留词池和生成历史 |
| 导入文章、对话、笔记 | 保留全文，映射内置文章 ID，保持引用关系 |
| 日记、自定义词库、标注范围 | 保留正文、批改、词条及设置 |
| 累计已学词 | 参与新每日计划的排除集合 |
| 无日期的旧每日词表与完成列表、旧每日数量 | 保留在 `legacy` 中，不冒充今日完成情况；新版默认每日 50 个 |

旧 `wb_*` 键和新版 `legacy` 学习快照均保留，API Key 不进入 `legacy`。旧有效加入日期决定初始到期安排；无效日期的旧词次日安排。六轮完成后可重新开始并保留新版历史。

正式数据与预览 `tt_preview_*` 隔离。新备份为 `app: tt-study, version: 2`，恢复前检查词数和文章数，用户确认后替换新版学习记录，不改旧记录或 Key。不要通过清空浏览器存储排查迁移问题。

## 代码组织

- `index.html` / `features.css`：已确认的 Apple 风格及预览壳。
- `features.js` / `core.js`：学习、复习、生成、阅读与悬浮助教。
- `migration.js`：旧学习记录迁移与校验。
- `extras.js`：原有日记、词库功能。
- `production.js` / `dictionary.js`：正式版笔记、词汇标注、查词、新闻、数据备份与设置。
- `ai-client.js`：统一请求、取消、限流退避和超时保护。
- `scripts/build-source.cjs`：内联上述模块，生成可独立打开的正式入口。

源码不包含凭据。`scripts/source-config.json` 中的旧 Key 指纹只用于识别并停用旧页面自带的共享 Key，无法用来调用 API。

## 验证边界

已用模拟的旧版全套数据验证迁移、重复打开、原键保留、损坏数据停止、写入失败、日记批改、自定义词库参与背诵、文章末段提问、笔记保存、刷新续学及不含 Key 的备份。共享预览的背诵、限流失败保护、拖动浮窗、窄屏和减少动效回归通过。

这些测试没有读取用户浏览器里的实际学习记录，没有调用真实千问服务。AI 服务账号限流仍由服务商控制；本次没有继续处理账号侧限流。PDF/OCR、Guardian 实际跨域、真实手机仍需实际使用验收。

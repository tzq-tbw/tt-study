# Tt-study UI 设计规范

确认日期：2026-10-20。适用于本项目后续 UI 实现和改版。

## 1. 已确认的方向和参考

用户认可保留大卡片结构的黑白 Apple 应用风格，并认可在此基础上增加原生应用手感的动效。

视觉与交互参考：[首页动效预览](../outputs/tt-study-apple-motion/index.html)。正式入口为 [英语学习工具](../outputs/wordbloom.html)。2026-10-22 已授权迁移此视觉和交互；正式数据迁移见 [迁移说明](MIGRATION.md)，预览继续使用隔离存储。

这里的“Apple 风格”指网页中的排版、表面层次和交互手感，不代表使用 Apple 原生控件或已通过 iPhone 真机验收。

## 2. 布局与内容层级

- 保留大卡片作为主要内容容器，不把界面改成密集表格或后台管理面板。
- 桌面保留左侧导航、右侧主要内容区。内容区控制最大宽度，宽屏上不无限拉伸。
- 首页保留今日学习计划、今日单词/已完成/错题本/英语日记统计、四个快捷入口、一键查词和学习提示。
- 导航保留：首页、每日背诵、每日时报、英语日记、错题本、语境造句、自定义词库、设置。
- 计划卡片突出标题和主要行动，进度环作为辅助反馈；快捷卡片明确显示四级、六级、考研、阅读入口。
- 中文标题、说明、数字和辅助文字通过字号、字重与间距区分层级。装饰性英文不能取代必要的中文功能名称。
- 不用虚构学习成果、连续打卡或个人信息填充空白。原版内容较多时，以实际可读性调整布局，不为匹配示例裁掉功能。

## 3. 视觉参数

以下值来自已确认预览，作为默认起点；根据内容和窄屏做小幅调整，维持同一视觉体系。

| 项目 | 默认值或要求 |
| --- | --- |
| 页面背景 | `#f5f5f7` |
| 卡片表面 | `#ffffff` |
| 主文字 | `#202023` |
| 次级文字 | `#717176`；小字和弱对比文字用于辅助信息，必要内容须检查可读性 |
| 细分隔线 | `#e9e9ec` |
| 主按钮 | 近黑底、白字；默认背景 `#29292c` |
| 大卡片圆角 | 约 `24px` |
| 统计、快捷卡片圆角 | 约 `19–21px` |
| 按钮、输入框圆角 | 约 `10–11px` |
| 默认卡片阴影 | `0 4px 22px #20202305, 0 1px 3px #20202304` |
| 桌面侧栏 | 约 `222px`，浅灰表面、细分隔线 |
| 主内容最大宽度 | 约 `1110px` |
| 卡片间距 | 约 `14–17px`，区块之间适当加大 |
| 字体 | 优先 `-apple-system`、`BlinkMacSystemFont`，回退到 `Segoe UI`、`PingFang SC`、`Microsoft YaHei` |

- 通过灰白表面、圆角、留白和轻阴影形成层次，避免大面积粗黑边框、直角及偏移的硬阴影。
- 保持黑白灰为主，不主动加入彩色渐变、霓虹、装饰插图或大面积玻璃效果。背景虚化用于弹窗的前后景区分。
- 图标沿用原项目的含义和资源，线条统一、端点柔和；必要时用浅灰圆角底托起图标。不要用 emoji 替换功能图标。
- 数字使用等宽数字特性 `font-variant-numeric: tabular-nums`，减少计数更新时的横向抖动。

## 4. 组件交互

- 大卡片整块可点击时，悬停、按下、键盘焦点都应有反馈；标题与箭头表达同一个动作。
- 主按钮突出主要行动，避免整页多个同等抢眼的主按钮。
- 输入框获得焦点时，表面稍亮，边框与外圈轻微强化；不移除可见焦点反馈。
- 弹窗使用原生 `dialog` 的模态、焦点管理和 Esc 关闭能力。关闭后焦点返回触发入口；更换弹窗内容后保持键盘可继续操作。
- 查词结果保持单词、音标/词性、释义、例句的阅读顺序。新动效不能遮挡结果或推迟用户操作。
- 未实现的预览入口明确说明预览范围，不能伪装成已经完成的业务功能。

## 5. 动效规范

整体手感：短距离、轻回弹、快响应。动效只用于表达进入、按下、层级变化和状态更新，不循环播放装饰动画。

| 场景 | 默认表现 |
| --- | --- |
| 页面初次进入 | 内容轻淡入并上移约 `12px`，缩放由 `.985` 恢复到 `1`；约 `600ms` |
| 卡片依次出现 | 小幅错开，延迟约 `45–295ms`；不能为了入场动画阻止点击 |
| 桌面卡片悬停 | 上抬约 `5px`、最大约 `1.012` 倍缩放，阴影轻增强；箭头右移约 `3px` |
| 按钮按下 | 缩放约 `.955`，约 `85ms` 立即响应；松开用回弹曲线恢复 |
| 卡片按下 | 缩放约 `.965`，约 `95ms`；恢复时平滑回弹 |
| 弹窗展开 | 从下方约 `12–16px`、约 `.95–.96` 倍缩放恢复，淡入约 `200ms`，回弹约 `340ms` |
| 弹窗背景 | 约 `220ms` 渐暗并增加至约 `7px` 虚化；关闭时同步退出 |
| 单词切换 | 新词卡由右侧约 `9px` 轻移入并淡入，约 `320ms` |
| 进度更新 | 进度条约 `650ms`、进度环约 `800ms` 平滑变化 |

默认曲线：

```css
--spring: cubic-bezier(.22, 1.35, .36, 1);
--ease: cubic-bezier(.22, 1, .36, 1);
```

- 优先 CSS 的 `transform`、`opacity` 和过渡，避免为这组动效新增动画依赖。
- 初次入场动画结束后释放 `transform` 的控制，不能因 `animation-fill-mode` 导致悬停或按下效果失效。
- 弹窗退出优先使用 `display` / `overlay` 的离散过渡。浏览器不支持时直接正常关闭，不能为了动画破坏模态行为。
- 触屏不套用鼠标悬停效果，保留按下反馈。动画不改变点击区域或页面正常排版。
- 尊重 `prefers-reduced-motion: reduce`：关闭入场、位移、回弹和相关过渡；内容与功能仍正常可用。
- 当前预览保留右上角“动效”开关以供对比。关闭后不再播放动画；该开关目前是预览控件，不自动视作正式版新增设置。

## 6. 响应式与基本可用性

- 窄屏按内容改为两列卡片，避免固定宽度造成横向溢出。参考预览在 `1100px` 以下将快捷入口改成两列。
- 参考预览在 `700px` 以下移除固定侧栏，导航改为顶部可横向滚动的按钮列；正文不因导航长度横向溢出。
- 统计卡片在手机上用两列，进度环适当缩小，查词输入框和按钮仍可正常操作。
- 手机上的主要触控区域至少 `44px`；键盘焦点清晰，弹窗能用 Esc 退出。
- 不通过隐藏正文或缩到难读的字号解决布局问题。设计参数服从可读性、功能完整和操作便利。

## 7. 后续改版的验证边界

- 对实际改动检查桌面和约 `390px` 窄屏，关注文字截断、横向溢出、触控区域与弹窗边界。
- 有新增交互时检查正常操作、关闭/返回、键盘焦点以及动效关闭后的行为。只做视觉微调时不额外编写重复实现的测试。
- 与正式产品接合时，验证学习数据、词库选择及原页面入口仍有效；不能拿独立预览的演示通过代替正式功能验收。
- 2026-10-22：错题本、艾宾浩斯复习、语境造句、辅助阅读、设置已沿用此风格完成独立预览，并检查桌面及 390px 窄屏。尚未完成真实 iPhone、真实 AI 服务和正式功能迁移验收。

## 8. 新增学习页面（2026-10-22）

- 导航增加独立的“艾宾浩斯复习”和“辅助阅读”；原有入口保留。
- 错题本使用卡片与三个自动状态灯，显示实际轮次和下一次日期；批量加词通过原生模态对话框预览、编辑后保存。
- 复习页突出单张回忆卡与展开答案操作，答案展开后再显示“记得 / 忘了”，不以浏览或生成内容计完成。
- 语境造句使用“今日错词 / 自由添加”切换，词条与生成结果保持分区。
- 辅助阅读保留完整正文，对话通过全站可拖动悬浮窗呈现。自由输入框是主要入口，引用作为独立信息块，不能用固定问题选项替代自由提问。
- 新增学习记录只写预览存储，不读取正式记录。真实 API 需要在设置中配置，不能用模拟响应伪装在线成功。

## 9. 功能保留修订（2026-10-22）

- 每日背诵使用完整词库的每日 50 词固定计划，每组最多 5 词，未学会的词承接到下一组。两个主要动作是“忘记了 / 已学过”，保留上一个、发音、手动加入错题本；例句手动展开并自动收词。本组结束展示逐词状态，不用浏览数量替代完成数量。
- AI 助教按用户澄清改为全站可拖动悬浮窗：不铺满窗口、不新增独立导航栏目。入口与标题栏均可拖动，切换页面保留当前对话与草稿；自由提问不依赖快捷问题，独立对话与文章对话分开。
- 选区通过真实鼠标拖选验证，引用保留文章 ID、段落与文字位置；点击提问不重建正文，不默认引用第一段。触屏真机选择仍需设备验收。
- 每日时报使用横向文章列表，日期从新到旧，保留稳定的今日阅读及前后篇导航。日期、来源和删除入口不能因视觉改版被省略。
